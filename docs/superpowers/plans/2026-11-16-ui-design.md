# UI design pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give FamChat its own warm visual identity ("Porch light"), polish every screen, and make the
layout, motion and accessibility hold up from phones to desktops, without changing behavior.

**Architecture:** One theme module (`app/lib/theme/`) owns colors, type, shape, spacing, motion and a
`ThemeExtension` for chat-specific tokens; screens read tokens from the theme only. Small shared
widgets (`app/lib/widgets/`) carry the repeated pieces (avatar, empty state, settings group, typing
dots, appear-in animation, content width). Grouping, day separators, avatar colors, contrast and the
quick switcher's ranking are pure functions with unit tests.

**Tech Stack:** Flutter 3.50 / Dart 3.14, `material_ui`, Riverpod 3, go_router 18. New dev deps:
`flutter_launcher_icons`, `flutter_native_splash`. Fonts bundled as assets (OFL).

**Spec:** `docs/superpowers/specs/2026-11-15-famchat-design.md` ("Client"), roadmap row 11.

## Global Constraints

- One pane on phones; list + conversation side by side from `ChatsShell.twoPaneWidth` (720 px).
- Light and dark themes, following the system setting.
- Text contrast ≥ 4.5:1 for every text/background pair the theme defines (both brightnesses).
- Fonts ship as assets; no runtime font fetching. Licenses (OFL) committed beside the fonts.
- Behavior identical: same routes, same admin gating, same keys used by tests where possible.
- Respect `MediaQuery.disableAnimations`; no infinite animation while it is set.
- Key screens render at 2.0 text scale on a 400×800 window without overflow.
- Chat widget tests use `chatTestWidgets` / `inApp` (`app/test/support/chat_harness.dart`).
- One build/test process at a time; no local desktop/mobile builds; one `flutter build web --release` at the end.

## Visual identity: "Porch light"

The light left on for family. Daytime is lilac paper and dusk-ink type; evening (dark mode) is a
dusk-purple room. In both, *your* messages glow amber like a lit window. Boldness is spent in one
place: the amber bubble and the house-shaped speech-bubble mark with a lit window. Everything else is
quiet.

| Token | Light | Dark |
|---|---|---|
| Dusk (ink, primary in light) | `#2E2550` | surfaces `#1B1626`…`#342C42` |
| Porch amber (my bubble, badges, primary in dark) | `#FFC75A` bubble / `#8A5A00` text-safe | `#F2B347` |
| Lilac canvas | `#F6F4FA` | `#1B1626` |
| Hydrangea (links, focus, tertiary) | `#4B44C6` | `#B7B1FF` |
| Error | `#B3261E` | `#FFB4AB` |
| Fern (presence) | `#2E9E5B` | `#5BD08A` |

Type: **Familjen Grotesk** (OFL; headings, names, the wordmark) and **Atkinson Hyperlegible Next**
(OFL; body and labels, designed for low-vision readers, which suits grandparents). Message text is
16 px. Shape: radii 6/10/16/22/pill; buttons are pills; inputs filled, no outlines. Spacing 4/8/12/16/24/32/48.
Eight per-person hues (marigold, coral, hydrangea, fern, plum, sky, rose, teal) picked by a stable hash
of the user id; the initial's color is chosen for contrast.

## Review Focus

1. Long names and 200 % text in chat tiles, conversation header and composer: must truncate, not overflow. (Task 8 test.)
2. A run of messages across midnight: day separator appears and grouping breaks at the day boundary. (Task 4 test.)
3. Typing indicator under tests / reduced motion: no endless animation, text still readable. (Task 3/4 tests.)
4. Settings for a member vs an admin: admin-only entries hidden for members, routes still gated. (Task 6 test.)
5. Quick switcher with no match / empty query: no crash, Enter does nothing without a selection. (Task 5 test.)
