# App Links for Invites Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tapping `https://famchat.dev/join#<token>` opens the installed app on Join with the invite filled in.

**Architecture:** The Worker serves the iOS and Android association files from `/.well-known/`. The app declares famchat.dev, and a Dart listener (app_links) turns incoming `/join` links into the pending invite that Join reads. On a phone browser, the web Join screen offers the app.

**Tech Stack:** Cloudflare Worker (Hono), Flutter, the app_links package.

**Spec:** docs/superpowers/specs/2026-11-17-app-links-design.md

## Global Constraints
- Links handled: `https://famchat.dev/join` only, with the token in the fragment.
- The iOS app ID is `<TEAM_ID>.dev.famchat.app`. The Android package is `dev.famchat.app`.
- Worker vars: `APPLE_APP_ID` (for example `ABCDE12345.dev.famchat.app`) and `ANDROID_CERT_SHA256` (comma-separated `AA:BB:…` fingerprints).
- Flutter's built-in deep linking is off on both platforms (it drops the fragment).

## Review Focus
- A link arriving while the app is open on another screen: Join opens with the new invite (test in Task 2).
- A link that isn't an invite (`/join` without a token, another path): ignored, no navigation (test in Task 2).
- Signed in when an invite arrives: stays put and shows "You're already signed in." (test in Task 2).
- Association files with no vars set: the Worker answers 404, not an empty or broken file (test in Task 1).
- The Apple file served with `content-type: application/json` and no redirect (test in Task 1).

### Task 2: The app opens invite links

**Files:**
- Create: `app/lib/session/app_links.dart`
- Modify: `app/lib/session/session_controller.dart` (pending invite becomes a Notifier), `app/lib/screens/join_screen.dart`, `app/lib/main.dart`, `app/ios/Runner/Runner.entitlements`, `app/ios/Runner/Info.plist` (`FlutterDeepLinkingEnabled` false), `app/android/app/src/main/AndroidManifest.xml` (verified intent filter for https famchat.dev `/join`; meta-data `flutter_deeplinking_enabled` false), `app/pubspec.yaml` (app_links)
- Test: `app/test/session/app_links_test.dart`, `app/test/screens/join_screen_test.dart`

**Interfaces:**
- Produces:
  - `final pendingInviteProvider = NotifierProvider<PendingInvite, String?>` with `set(String?)`. It replaces `initialInviteTokenProvider`; main's web token seeds it.
  - `abstract interface class IncomingLinks { Stream<Uri> get links; Future<Uri?> initial(); }`, with `incomingLinksProvider`. The real one uses app_links on Android and iOS; elsewhere there are no links.
  - The `InviteLinkListener` widget sits in the app root's builder stack next to `ShareInbox`.

- [ ] **Step 1: Write the failing tests.** Use a fake `IncomingLinks`:
  - Signed out, link `https://famchat.dev/join#<valid token>`: Join is shown and its invite field holds the token, so no paste is needed.
  - Signed out on another screen (`/pair`), then a link arrives: Join is shown with the new token.
  - Links `https://famchat.dev/join`, `https://famchat.dev/other#x` and `https://evil.example/join#<token>`: nothing happens. Only the famchat.dev host counts.
  - Signed in when a valid invite arrives: no navigation, and the snack bar says "You're already signed in."
- [ ] **Step 2: Run** `flutter test test/session/app_links_test.dart`. Expected: FAIL (missing types).
- [ ] **Step 3: Implement.**
  - `PendingInvite` and `IncomingLinks` as above.
  - The listener parses with `inviteTokenFromUri` plus the host check, then sets the pending invite and goes to `/join` when signed out.
  - Join reads the provider through `ref.watch`, so an invite that arrives later still fills the field.
  - Entitlement: `com.apple.developer.associated-domains = [applinks:famchat.dev]`.
  - Android `<intent-filter android:autoVerify="true">` with VIEW, DEFAULT and BROWSABLE, plus `scheme=https host=famchat.dev pathPrefix=/join`.
- [ ] **Step 4: Run** the tests. Expected: PASS. Then run the full app suite.
- [ ] **Step 5: Commit** `feat: invite links open the app`.
