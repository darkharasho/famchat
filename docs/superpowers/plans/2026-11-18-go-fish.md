# Go Fish (PR 1: shared seed + Go Fish) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a seeded random generator to game messages and ship Go Fish as the seventh DM game.

**Architecture:** `game` messages gain an optional `seed`. A web-safe xorshift32 generator and a
Fisher–Yates shuffle (`lib/games/rng.dart`) turn the seed into the same deck on every device.
`GoFishBoard` implements the existing `Board` interface, with `toMove` derived from the position.
Everything else (replay, cache, labels, bar, card, resign, rematch) carries over unchanged.

**Tech Stack:** Flutter/Dart, Riverpod, flutter_test (VM and `--platform chrome`).

**Spec:** `docs/superpowers/specs/2026-11-18-go-fish-and-landlord-design.md` (sections "Luck and
secrets" and "Go Fish"). Landlord and the long-game slot are PR 2 and get their own plan.

## Global Constraints

- Branch `feat/go-fish-landlord`. Work in `app/`. Run builds and test runs one at a time.
- Never run app integration tests against the real keyring or D-Bus. Unit and widget tests only.
- Never trigger 1Password. If commit signing needs an unlock, stop committing and report it.
- Wire name `gofish`, title `Go Fish`. `drawOffers` false. The win reason is `books`.
- `seed` is an integer in `0..4294967295`, read with `wireInt`. A `gofish` game without a valid
  seed is inert. Older game types ignore the seed, and new phones never send one for them.
- Generator (permanent wire format): state = seed, or `0x9E3779B9` if the seed is 0. Step:
  `x ^= (x << 13) & 0xFFFFFFFF; x ^= x >> 17; x ^= (x << 5) & 0xFFFFFFFF`, then return `x`.
  `randInt(n) = next() % n`. Shuffle: for `i` from `len-1` down to 1, swap `i` with
  `randInt(i + 1)`. No multiplication.
- Cards are `0..51`: rank = `card ~/ 4 + 1` (1 = ace … 11 = J, 12 = Q, 13 = K), suit = `card % 4`
  (♠ ♥ ♦ ♣). The deck starts in order `0..51`.
- Hidden information: the UI never renders the opponent's cards or the stock order. Pushes,
  timeline lines and the log never name a card drawn on "Go fish" to the opponent unless it matched.
- Glyphs must not render as emoji (use Noto Sans Symbols 2).

## Review Focus

1. **A seed above 2^31 decoded on the web.** Both platforms must deal the same hands. This is
   pinned by golden values run on Chrome (Task 1) and a decode test with `3735928559` (Task 3).
2. **A `gofish` message with a missing, negative, fractional or too-large seed** (an old or
   hand-made client). The game must be inert, not crash or deal from seed 0. Task 3 tests this.
3. **The player to move has an empty hand and the stock is empty.** The turn must pass to the
   other player instead of stalling. Task 2 tests this.
4. **A lucky draw or a match that empties the mover's hand.** The mover goes again: they draw one
   card if the stock has any, or the turn passes otherwise. Task 2 tests this.
5. **The opponent's hand reaching the screen**, through the card thumbnail or the log after a
   failed "Go fish". Task 4 tests this.

### Task 2: Go Fish rules

**Files:**
- Create: `app/lib/games/go_fish.dart`
- Test: `app/test/games/go_fish_test.dart`

**Interfaces:**
- Consumes: `Rng`, `shuffled` (Task 1); `Board`, `Side`, `Outcome`, `wireInt` (`rules.dart`).
- Produces:
  - `class GoFishBoard implements Board` with `factory GoFishBoard.deal(int seed)` and
    `@visibleForTesting factory GoFishBoard.custom({required List<int> firstHand, required List<int> secondHand, required List<int> stock, List<int> firstBooks = const [], List<int> secondBooks = const [], Side turn = Side.first})`.
    `custom` lays no books itself.
  - `static int rankOf(int card)`, `static int suitOf(int card)`
  - `List<int> hand(Side s)`: sorted ascending.
  - `List<int> books(Side s)`: ranks, in the order they were made.
  - `int get stockCount`
  - `(int, int) get scores`: book counts.
  - `List<GoFishEvent> get events`: oldest first, capped at the last 200.
  - `class GoFishEvent { final Side asker; final int rank; final int given; final int? drawn; final bool again; final List<(Side, int)> booked; }`.
    `given` is the number of cards handed over. `drawn` is the card drawn on "Go fish" (null if
    there was no match and no stock, or if there was a match). `again` says whether the asker goes
    again. `booked` holds (holder, rank) for books laid by this play.

- [ ] **Step 3: Implement `GoFishBoard` in `lib/games/go_fish.dart`**

Follow `dots_and_boxes.dart`: a private constructor, unmodifiable lists, and `play` returning null
when the move is illegal. The order inside `play`:
1. Ask, then either the hand-over or the draw.
2. Lay books in the mover's hand, then the opponent's.
3. Empty-hand draws, mover first.
4. Set the stored turn: the mover if `again`, otherwise the other player.

`toMove` = the stored turn, unless that player has no cards and the stock is empty, in which case
it's the other player. `outcome` is set once 13 books are made: `Outcome(more books, 'books')`.
